DeepSeek Harness 开发版安装

本开发包尚无已发布的商店页或配套安装程序下载入口。请使用同一个可信开发包中的组件。

  1. 先安装并启动你已有的 DeepSeek Harness。
  2. 在开发包根目录阅读 README.md，按已验证的安装指引安装 dsh 宿主插件，并运行显式的当前用户桥接注册步骤。
  3. 打开 Chrome 的扩展程序管理页，启用开发者模式，选择“加载已解压的扩展程序”，加载开发包中的 extension 目录。
  4. 返回侧栏点击“检测 / 修复连接”，等待真实握手。文件已准备就绪不代表插件已安装。

Chrome 无法在本机组件缺失时执行安装命令。不要把网页提供的任意地址或命令作为安装来源。重新加载、安装与修复都不会自动提交引用或重发消息。

连接仍失败时，检查 dsh 是否已运行、宿主包是否已加载，以及本机注册是否允许当前开发扩展 ID。版本不兼容时请使用同一发布包更新两端。
